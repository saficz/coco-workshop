## Plan: Create `COCO_WORKSHOP.PIPELINE_LAB.SILVER_AP_INVOICES` Dynamic Table

### Context
Two Bronze AP invoice tables with different column names but semantically identical fields need to be unioned into a single conformed Silver schema. The target schema `PIPELINE_LAB` exists.

### Unified Column Mapping

| Silver Column | SAP Source | Oracle Source |
|---|---|---|
| INVOICE_ID | INVOICE_ID | INV_ID |
| INVOICE_NUMBER | INVOICE_NUMBER | INV_NUM |
| VENDOR_ID | VENDOR_ID | SUPPLIER_ID |
| VENDOR_NAME | VENDOR_NAME | SUPPLIER_NAME |
| INVOICE_DATE | INVOICE_DATE | INV_DATE |
| DUE_DATE | DUE_DATE | PAYMENT_DUE_DATE |
| INVOICE_AMOUNT | INVOICE_AMOUNT | TOTAL_AMOUNT |
| CURRENCY_CODE | CURRENCY_CODE | CURRENCY |
| PAYMENT_TERMS | PAYMENT_TERMS | TERMS_CODE |
| PO_NUMBER | PO_NUMBER | PURCHASE_ORDER |
| LINE_DESCRIPTION | LINE_DESCRIPTION | DESCRIPTION |
| GL_ACCOUNT | GL_ACCOUNT | ACCOUNT_CODE |
| COST_CENTER | COST_CENTER | DEPT_CODE |
| APPROVAL_STATUS | APPROVAL_STATUS | STATUS |
| CREATED_AT | CREATED_AT | CREATION_DATE |
| SOURCE_SYSTEM | 'SAP' (literal) | 'ORACLE' (literal) |
| SOURCE_IDENTIFIER | SAP_COMPANY_CODE | ORACLE_ORG_ID |

### Implementation
Single DDL statement:
```sql
CREATE OR REPLACE DYNAMIC TABLE COCO_WORKSHOP.PIPELINE_LAB.SILVER_AP_INVOICES
  TARGET_LAG = '1 hour'
  WAREHOUSE = <current warehouse>
AS
SELECT <mapped columns from SAP with SOURCE_SYSTEM='SAP'>
UNION ALL
SELECT <mapped columns from Oracle with SOURCE_SYSTEM='ORACLE'>;
```

- `TARGET_LAG = '1 hour'` — reasonable default for a Silver layer refresh cadence.
- Includes a `SOURCE_SYSTEM` discriminator and `SOURCE_IDENTIFIER` (company code / org ID) for traceability.

### Verification
- `SELECT * FROM COCO_WORKSHOP.PIPELINE_LAB.SILVER_AP_INVOICES LIMIT 10` to confirm data flows.
- Row count should equal SAP rows (15) + Oracle rows (15) = 30.
